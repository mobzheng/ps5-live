1

PS5 的 DNS

PS5 的直播流量要先到这台电脑，所以在 PS5 里把它设成 DNS。

—
在 PS5 上怎么填
  1. 设置 → 网络 → 设定互联网连接
  2. 选中正在用的 Wi-Fi 或 LAN → 按 选项 键 → 详细设定
  3. DNS 设置 → 手动 → 主 DNS 填上面的地址
  4. 保存后重新测试互联网连接，能连上就行
2

OBS 的播放地址

在 OBS 里加「媒体源」，把地址粘进去。地址固定不变，PS5 换流名也不影响。

—
低延迟 PS5 开播后显示
OBS 里怎么加
  1. 来源 → + → 媒体源 → 新建
  2. 取消勾选「本地文件」，输入 里粘贴上面的地址
  3. 勾选 重新连接（PS5 开播/重开都能自动接上）
  4. 想要 1–2 秒延迟：改用 VLC 视频源，填 RTMP 地址
