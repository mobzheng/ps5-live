1PS5 的 DNS 填这个

PS5 的直播流量会先到这台电脑，所以要让 PS5 用这台电脑当 DNS。

—
在 PS5 上怎么填（点开看步骤）
  1. PS5 主界面 → 设置 → 网络 → 设定互联网连接
  2. 选中你在用的 Wi-Fi（或 LAN 线）→ 按 选项 键 → 详细设定
  3. 找到 DNS 设置 → 改成 手动 → 主 DNS 填上面的 IP
  4. 保存后重新 测试互联网连接，能连上就成功了

2OBS 的播放地址

PS5 开始直播后，在 OBS 里添加「媒体源」，把地址粘进去就能看。地址永远不变。

—
OBS 怎么加 / 低延迟怎么选
  1. OBS → 来源 → + → 媒体源 → 新建
  2. 取消勾选「本地文件」，在 输入 里粘贴上面的地址
  3. 勾选 重新连接（重要：这样 PS5 开始/结束直播都能自动接）
  4. 想要更低的延迟（约 1–2 秒）：改用 VLC 视频源，填 RTMP 地址
